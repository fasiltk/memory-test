# 🧠 Human Memory Test Game

A fun and interactive memory challenge built with **Django**, **Python**, **HTML**, **CSS**, **JavaScript**, and **SQLite**.

## 📖 About the Project

Human Memory Test Game is a web-based application designed to test and improve a user's visual memory.

The game starts by displaying **12 numbered images** on the screen. Players are given a few seconds to memorize the image-number combinations. After the timer expires, all images disappear, and only **one random image** is shown.

The player's task is to **identify the correct number associated with the displayed image**.

- ✅ Correct answer → **You Win**
- ❌ Wrong answer → **You Lose**

This simple yet engaging game helps evaluate and train short-term visual memory skills.

---

## 🎮 How It Works

1. The game loads **12 images**, each assigned a unique number.
2. Images remain visible for a limited time.
3. After the countdown:
   - One random image is displayed.
4. The user select the number that was originally associated with the image.
5. The system checks the answer and displays the result.

---

## 🚀 Features

- Display 12 numbered images
- Countdown timer before images disappear
- Random image selection
- User answer validation
- Win/Lose result page
- Responsive user interface
- Simple and lightweight SQLite database
- Built using Django MVC architecture
